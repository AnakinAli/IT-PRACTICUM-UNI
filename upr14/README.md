# Упражнение 14 — снимка като BLOB

JSF/Java EE 8 приложение за регистрация на потребители, запис на профилна
снимка като `MEDIUMBLOB` в MySQL, списък на профилите и отделна страница за
всеки профил.

## Стартиране

Необходими са Docker и Docker Compose:

```bash
docker compose up --build
```

След успешно стартиране отворете <http://localhost:8081/upr14/>.

За спиране:

```bash
docker compose down
```

Данните остават в Docker volume `mysql_data`. За учебни цели паролата се пази
и визуализира като обикновен текст, както е зададено в условието. В реално
приложение тя задължително трябва да бъде хеширана и никога да не се показва.
