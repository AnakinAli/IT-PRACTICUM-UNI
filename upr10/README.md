# JSF Ajax office filter

Примерен JSF 2.2 проект, който филтрира офиси с `<f:ajax>` при всяко
натискане на клавиш.

## Стартиране в IntelliJ IDEA

1. Изберете JDK 8 или по-нова версия като Project SDK.
2. Изчакайте Maven да зареди зависимостите.
3. Изберете готовата Run конфигурация **Jetty** и натиснете **Run**.
4. Отворете <http://localhost:8080/upr10/>.

Алтернативно изпълнете Maven goal `jetty:run` от Maven прозореца на IDE.

Търсенето приема име или част от име на град. След първата запетая може да
се въведе и част от адрес, например `Русе, Липник`.
